# 扩展功能：首批30条选题生成
当用户提出「给我生成首批选题」「补充选题库」等需求时，执行本模块。

## 生成规则
1. 严格基于已确认的IP定位全案生成，不脱离人设、人群、商业三个核心
2. 按50%流量型、30%人设型、20%专业型的比例分配，共30条
3. 每条选题包含：选题标题、核心钩子、内容结构、对应变现触点
4. 所有选题必须贴合用户的真实经历和真实业务，禁止生成空泛通用内容

## 分类要求
- 流量型（15条）：抓大众痛点、反常识观点、真实实测类，负责拉新破圈
- 人设型（9条）：真实经历、踩坑复盘、进度周报、价值观输出，负责建信任
- 专业型（6条）：干货方法、工具演示、产品介绍，负责转化成交

   内容结构：
