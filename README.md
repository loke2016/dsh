# 顶尖IP定位顾问 · DeepSeek Harness 插件

把「五阶段访谈式个人 IP 定位」装进 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)：左侧栏底部多一行 **顶尖IP定位顾问**，点一下就用专属人设新开一个对话，输入框里已经预填好开场语，回车即开始访谈。

人设是特劳特（Trout）：一个只谈话、不干活的定位顾问——不挂任何工具，不读写你的文件，也不跑命令。

## 它做什么

- **五阶段访谈**：Step 0 动机与资源 → Step 1 人群 → Step 2 人设 → Step 3 商业 → Step 4 内容 → Step 5 收尾定稿。
- **每阶段有小结**：先提问、再追问细节、最后给结构化小结；你不确认，它不往下走。
- **铁律两条**：商业不闭环不聊内容；结论必须有真实数字和真实案例支撑，形容词无效。
- **按模板交付**：收尾输出《个人IP定位全案》，标题、小节顺序、表格结构固定。
- **可追加选题库**：说「给我生成首批 30 条选题」，按 50/30/20 出流量型 15 / 人设型 9 / 专业型 6。
- **长访谈不丢结论**：对话过长时自动压缩旧内容，只保留已确认的阶段小结、关键数字和原话。

## 安装

需要 DSH 0.2 及以上（Web 版、桌面版都可以）。

**方式 A：图形界面**

1. 打开左侧栏的「插件」页 → 添加插件；
2. 粘贴 `github:loke2016/dsh`；
3. 装好后按提示重启（桌面版：应用菜单 → 重启应用与 Host）。

**方式 B：命令行**

```bash
dsh plugin --profile desktop add github:loke2016/dsh
```

> ⚠️ 装完必须重启一次。这个插件带一个新的 Agent 预设和一个侧栏入口，两者都在 Host 启动时装配；只刷新页面不够。

## 使用

1. 点侧栏底部 **顶尖IP定位顾问**；
2. 输入框里已有「帮我做个人IP定位，现在开始五阶段访谈。」——直接回车，或改成你自己的背景（一次性把业务、人群、产品说完也可以）；
3. 按引导走完五个阶段，每步核对小结，有偏差当场改；
4. 收尾拿到全案；之后可以要求调整某一节，或补选题库。

也可以跳过侧栏入口：在**新建会话**页的预设选择器里选「顶尖IP定位顾问」，效果相同。

> Windows 桌面版把侧栏收起时，DSH 会把整个侧栏底部隐藏（设置按钮同理），展开侧栏就能看到。

## 它是怎么构成的

| 文件 | 作用 |
|---|---|
| `cordis.patch.yml` | 声明 Agent 预设 `ip-advisor`（人设 + 时间上下文 + 自动压缩），并插入插件自身的行 |
| `index.js` | Host 半边：不提供任何服务，`apply()` 为空 |
| `client.js` | 浏览器半边：在 `sidebar.footer.action` 注册一个入口，点击时 `startSession` 到 `ip-advisor` 预设并预填开场语 |
| `locale/*.json` | 插件列表里的标题和说明 |
| `icon.svg` | 定位图钉图标 |
| `sources/` | 人设原文（三段纯文本），`cordis.patch.yml` 里的人设由它们生成 |
| `scripts/build-patch.mjs` | 把 `sources/` 组装成 `cordis.patch.yml` |

预设的组合只有三个插件：

```yaml
persona        # 人设（整份访谈手册内联在 prefix 里）
time-context   # 让顾问知道今天几号（全案要写定稿日期）
compaction     # 对话过长时自动压缩
```

没有挂任何工具，所以它不会调用 shell、不会改文件。

## 改人设

`cordis.patch.yml` 里那一大段人设是生成出来的，别手改。改这三份纯文本，然后重新生成：

- `sources/persona-full.md` — 角色、核心信条、五阶段提问清单 / 追问规则 / 小结模板
- `sources/plan-template.md` — 《个人IP定位全案》标准模板
- `sources/topics-30.md` — 首批 30 条选题的生成规则

```bash
node scripts/build-patch.mjs
```

改完重启 DSH 生效。想加行业专属追问规则，直接接在 `persona-full.md` 末尾。

## 已知边界

- 没有工作区时，预填的开场语没有落脚处，入口会退回 DSH 自带的「新建会话」页，此时需要手动选「顶尖IP定位顾问」。
- 每次点入口都是**新开**一轮访谈（旧对话不会续上），适合按项目分别定位；想接着上一轮聊，直接打开那次会话即可。
- 人设是纯对话，不会写文件；要落地成文档，让顾问把全案输出在对话里，再用 DSH 的其他能力保存。
